# X Video Downloader v1.1.1

Windows 10/11 x64 · Portable · No separate Python or FFmpeg installation required.

## Download

- **Recommended:** `XVideoDownloader-v1.1.1-windows-x64.zip` — extract and run `XVideoDownloader.exe`; includes instructions and license notices.
- `XVideoDownloader-v1.1.1-windows-x64.exe` — standalone executable.
- `x-video-downloader-v1.1.1-source.zip` — project source, tests and build instructions.
- `SHA256SUMS.txt` — SHA-256 checksums for these files.

## What's new

- English is now the default on first launch.
- Added full Traditional Chinese support.
- Five languages: English, 简体中文, 繁體中文, 日本語 and 한국어.
- Language changes apply immediately and are remembered.
- Existing saved language choices and save folders are preserved.

## Features

Paste an X / Twitter post link, select a folder and download the best available video quality. Includes multiple-video posts, progress, cancellation, retry, a flat scrollable interface, and optional user-supplied proxy and Netscape cookies.

Your network must be able to access X. Restricted or deleted posts may be unavailable. The app does not automatically read browser sign-in data.
