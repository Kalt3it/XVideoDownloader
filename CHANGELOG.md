# Changelog

## 1.1.1 — 2026-10-21

- English is now the default for first launch and missing or invalid language preferences.
- Added a complete Traditional Chinese interface, errors and help.
- Added Traditional Chinese locale aliases and font selection.
- Preserved explicit saved language choices and save locations.

## 1.1.0 — 2026-10-21

- Added live language switching for English, Simplified Chinese, Japanese and Korean.
- Added language-aware fonts, translated worker events and remembered language choices.
- Kept active downloads running while switching languages.
- Fixed language preference saving when a proxy field is incomplete.

## 1.0.2 — 2026-10-21

- Replaced the classic scrollbar with a narrow, flat, rounded control.
- Added drag, track-click and hover behavior; hid the thumb when scrolling is unnecessary.
- Unified flat button, entry and progress styles.

## 1.0.1 — 2026-10-21

- Added full-page scrolling for smaller windows and expanded network options.
- Fixed a completion-event race and false success for empty files.
- Added support for legacy native Twitter video redirects.

## 1.0.0 — 2026-10-21

- Initial Windows desktop downloader with progress, cancellation and retry.
